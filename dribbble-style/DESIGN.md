# Dribbble — извлечённый стиль

Источник: [dribbble.com](https://dribbble.com/). Публичная главная страница без авторизации, окно **1440 × 1000**, 12 ноября 2026 года. Автоматическая выборка TypeUI: **259 элементов**; ключевые компоненты дополнительно проверены через computed CSS и скриншот.

## Характер интерфейса

Белый фон, почти чёрный текст с фиолетовым оттенком, розовый акцент и крупный Mona Sans. Широкие поля и свободное пространство отделяют блоки; кнопки, поиск и фильтры имеют форму капсул. Изображения работ дают основной цветовой контраст. Это публичная витрина дизайнерских работ и услуг: аудитория — дизайнеры, заказчики и посетители, ищущие вдохновение.

Первый экран делится на текстовый блок слева и крупную карточку с меняющимися работами справа. Под ним расположены переключатели каталога, длинная строка поиска, небольшие тематические фильтры и сетка работ. Зелёный фон внутри работы в превью относится к содержимому карточки, а не к общей палитре интерфейса.

## Компоновка и размеры

- Горизонтальные поля основного контента: **72px**. Доступная ширина: **1296px**.
- Первый экран: `padding: 40px 72px 60px`.
- Ширина текстового блока: **618px**. Медиа справа: **614 × 430px**.
- Геометрическое расстояние между текстовым блоком и медиа: **64px**. Это измеренное расстояние, не значение CSS gap родителя.
- Внутри секции с заголовком, преимуществами и CTA: **32px** между блоками.
- Поиск: **56px** по высоте, на всю ширину основного контента.
- Основной CTA: **49px** по высоте; вход: **48px**; фильтры: **31px**.
- Горизонтальный padding кнопок: **24px**, фильтров: **16px**; расстояние между иконкой и текстом CTA: **8px**.

Это измерения одного состояния, а не универсальная сетка для любых экранов. Не переносить случайные большие отступы из статистической выборки в систему токенов.

## Скругления и поверхности

- Карточка медиа первого экрана: **24px**.
- Кнопки, поисковая оболочка и фильтры: полное скругление. На сайте вычисляется `1e+07px`; для аналогичной формы можно использовать `9999px`.
- Кнопка поиска: круг, **40 × 40px**, `border-radius: 50%`.
- Внутреннее поле поиска имеет радиус **12px**, внешняя оболочка — капсулу.
- У проверенных CTA, поиска и медиа отсутствует box-shadow. Общая поверхность плоская; границы тонкие. Другие элементы автоматической выборки содержат небольшие тени, перечисленные в `tokens.json → rawSample.shadowTokens`.

## Движение

В computed CSS обнаружены переходы:

| Элемент | Длительность | Easing |
| --- | --- | --- |
| Кнопки | 50ms | cubic-bezier(0.32, 0, 0.59, 0.03) |
| Тематические фильтры | 100ms | ease |
| Оболочка поиска | 200ms | cubic-bezier(0.34, 1.56, 0.64, 1) |

Заголовок содержит сменяемые названия направлений, медиа — несколько работ. Полная временная последовательность этих смен не измерялась. Значения transition выше не описывают длительность карусели и не подтверждают фактическое поведение hover/focus.

## Как применять референс

Сохранять белую основу, тёмные CTA, ограниченный розовый акцент, крупный заголовок и широкие поля. Использовать скругления по назначению: 24px для крупного медиа, капсулы для действий и поиска, круги для одиночных иконок. Цветные работы могут быть выразительными, тогда как окружение остаётся спокойным.

При создании нового интерфейса отдельно спроектировать адаптивность, клавиатурный фокус, состояния ошибок и reduced-motion. Это рекомендации для реализации, а не результат аудита Dribbble. Извлечение стиля не включает файлы шрифтов, логотипа или изображения работ.

## Файлы и достоверность

- `tokens.json` — проверенные значения с семантическими именами, назначенными для этого референса.
- `observations.json` — адресные измерения computed CSS и геометрии элементов.
- `preview.png` — скриншот первоначального захвата.
- `extraction.json` — происхождение, параметры и сведения о проверке.
- `SKILL.md` — инструкция для использования этого референса по явному запросу.

Первоначальная эвристика TypeUI ошибочно распознала dashboard, не включила розовый акцент в основную палитру и присвоила почти чёрному цвету имя inverse. В итоговом референсе это исправлено по наблюдаемой странице. Исходные частотные данные размеров, отступов и теней оставлены в rawSample с пояснением.

Охват: главная страница в одном десктопном размере. Авторизованные разделы, другие страницы, мобильные состояния, iframe/shadow DOM и интерактивные состояния не исследованы. Изображения карусели и сетки меняются между загрузками. Имена токенов здесь не являются исходными CSS-переменными сайта.
